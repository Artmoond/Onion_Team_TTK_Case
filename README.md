# 🗺️ Карта Пространства — ТТК (Хакатон 2026)

Сервис для навигации внутри зданий и на мероприятиях с интерактивным 2D-планом и 360° виртуальными панорамами.

---

## 🚀 Быстрый старт через Docker Compose в WSL

Вам **не нужно** ставить вручную Python, Node.js или базы данных на Windows. Всё поднимается одной командой:

```powershell
.\start.ps1
```
*(Или в терминале: `wsl docker compose up --build -d`)*

### Сервисы доступны по адресам:
- 📱 **Клиент посетителя (Mobile Web):** [http://localhost:3000](http://localhost:3000)
- 🛠 **Студия организатора (Admin Studio):** [http://localhost:3001](http://localhost:3001)
- 🚀 **Backend API & Swagger docs:** [http://localhost:8000/docs](http://localhost:8000/docs)

Остановка всех контейнеров:
```powershell
.\stop.ps1
```

## 👥 Структура репозитория и зоны ответственности (4 человека)

Каждый участник работает в **своей отдельной папке**, не создавая конфликтов в Git:

| Папка | Участник | Роль | Основная задача |
| :--- | :--- | :--- | :--- |
| `frontend-client/` | **Участник №1** | Lead Frontend (Mobile) | Мобильный интерфейс посетителя, 360° тур (Pannellum), гироскоп, карточки POI, пошаговая прогулка по маршруту. |
| `frontend-admin/` | **Участник №2** | Frontend Editor (Studio) | Редактор 2D-плана, расстановка POI, разметка графа коридоров, экспорт постоянных ссылок и QR-кода. |
| `backend/` | **Участник №3** | Backend & DevOps | REST API (FastAPI), алгоритм поиска кратчайшего пути $A^*$ (`app/core/pathfinder.py`), авторизация, деплой. |
| `cv-worker/` | **Участник №4** | CV, Data & Product | Сшивка панорам (OpenCV), сжатие в WebP (превью 1024px + HQ), заготовка демо-площадки, презентация и питч. |
| `shared/` | **Все** | Общие контракты | `types.ts` (TypeScript интерфейсы) и `mock_venue.json` (эталонный датасет отеля/экспоцентра). |

---

📱 Участник №1: Lead Frontend (Мобильный клиент посетителя)
Папка: frontend-client/ • Порт: 3000
Фокус: Скорость, адаптивность под экраны смартфонов, 360-панорамы и плавность интерфейса.

Фреймворк и сборка: React 18 + TypeScript + Vite (мгновенная загрузка бандла без оверхеда).
Стилизация: Tailwind CSS (мобильные классы, модальные шторки bottom sheet, анимации).
360° Панорамный движок: Pannellum.js (WebGL) (сверхлегкий вьюер сферических фотосфер 2:1, вращение жестами, хотспоты).
Датчики смартфона: DeviceOrientation API (гироскоп: обзор панорамы при повороте корпуса телефона).
2D-план здания: SVG / HTML5 Canvas или Leaflet.js (CRS.Simple) (масштабирование жестами pinch-to-zoom, анимированная неоновая полилиния пути).
Офлайн / Надежность: PWA (Service Worker + Cache API) (кэширование плана и превью панорам для работы без интернета).
Иконки: Lucide React (стрелки, маркеры, категории).
🛠 Участник №2: Frontend Engineer (Студия организатора / Редактор)
Папка: frontend-admin/ • Порт: 3001
Фокус: Удобный десктопный конструктор, интерактивная разметка плана и генерация QR.

Фреймворк и сборка: React 18 + TypeScript + Vite.
Стилизация: Tailwind CSS (двухколоночный интерфейс: панель инструментов слева, холст по центру).
Графический холст редактора: React-Konva (Konva.js) или интерактивный SVG/Canvas (drag-and-drop маркеров, кликабельная расстановка узлов графа, полигоны комнат).
Загрузка файлов: react-dropzone (перетаскивание файлов плана здания и фотосфер с компьютера).
Генерация QR-кода: qrcode.react / Canvas API (мгновенная генерация векторного QR-кода на публичную ссылку площадки и экспорт в PNG для печати).
Управление состоянием: Zustand или React Context + hooks (хранение истории изменений, undo/redo).
🚀 Участник №3: Backend, Алгоритмы и DevOps
Папка: backend/ • Порт: 8000
Фокус: Стабильный API, математика поиска кратчайшего пути, безопасность и деплой.

Язык и среда: Python 3.11+.
Веб-фреймворк: FastAPI + Uvicorn (ASGI) (асинхронный, автогенерация интерактивной документации Swagger UI по адресу /docs).
Валидация данных: Pydantic v2 (строгие схемы запросов и ответов маршрутизации).
Алгоритм indoor-навигации: A* (A-Star Pathfinder) на базе heapq / math (расчет пути по коридорам за 1–3 мс с учетом длины ребер и этажей).
База данных: PostgreSQL 16 (JSONB для хранения ревизий опубликованной карты) или SQLite (для мгновенного локального старта).
Безопасность и Auth: python-jose (JWT-токены), passlib / bcrypt (защита редактора, разграничение прав доступа IDOR).
Инфраструктура и деплой: Docker, Docker Compose, Caddy или Nginx (автоматический выпуск бесплатных SSL-сертификатов HTTPS на боевом сервере).
📷 Участник №4: CV, Обработка панорам, QA & Product
Папка: cv-worker/ + demo_assets/ + Презентация
Фокус: Сшивка фото, оптимизация графики, наполнение демо-стенда и защита проекта.

Компьютерное зрение (CV): OpenCV (opencv-python-headless) — модуль cv2.Stitcher_create(cv2.Stitcher_PANORAMA) (алгоритм автоматической сшивки серии кадров с телефона в панораму).
Оптимизация графики: Pillow (PIL) / pyvips (автоматическое сжатие панорам в WebP с генерацией двух слоев: быстрое превью 1024×512 и HQ-слой 4096×2048).
Дизайн и макеты: Figma (подготовка красивой векторной схемы демо-отеля/экспоцентра ТТК, фирменные иконки, макет бейджа с QR-кодом).
Тестирование: Chrome DevTools (Device Mode с эмуляцией мобильных сетей 4G/3G) + тестирование на реальных смартфонах (iOS Safari / Android Chrome).
Презентация и питч: PowerPoint / Keynote / Canva (питч-дек на 5 слайдов по регламенту ТТК) + OBS Studio (запись резервного 4K-видео прохода по карте на случай сбоя Wi-Fi на защите).
🤝 Точка соприкосновения всех участников:
Папка shared/:

shared/types.ts — зафиксированные TypeScript-интерфейсы моделей данных (POI, Panorama, Floor, NavGraph).
shared/mock_venue.json — эталонный JSON демо-площадки, позволяющий фронтендерам верстать и тестировать интерфейсы независимо от готовности базы данных.
