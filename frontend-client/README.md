# 📱 Мобильный клиент посетителя (Участник №1)

## Зона ответственности
- Клиентский опыт посетителя на смартфонах (Mobile-first, PWA).
- Интерактивный 2D-план этажей (SVG/Canvas/Leaflet).
- Полноэкранный 360° виртуальный тур (Pannellum / WebGL, хотспоты).
- Нижняя карточка точки (Bottom Sheet), отображение шагов маршрута.

## Вход
Карта открывается после входа или регистрации с ролью **посетитель**. Демо-аккаунт: `user@ttk.local` / `User12345!`.

Переключатель «Организатор» на экране входа ведёт в студию организатора. Адрес можно переопределить через `VITE_ADMIN_URL`, API — через `VITE_API_URL`.

## Запуск
Сервис автоматически поднимается в Docker Compose на порту **3000**:
http://localhost:3000

Для локального запуска без Docker:
```bash
npm install
npm run dev
```
