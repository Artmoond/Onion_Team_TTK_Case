# 📷 Обработка панорам, CV и Демо-стенд (Участник №4)

## Зона ответственности
- Алгоритм сшивки кадров в панораму (`OpenCV Stitcher`).
- Конвертация и сжатие панорам в WebP (превью 1024px + детальная 4096px).
- Подготовка идеального демонстрационного датасета (реальный отель / павильон ТТК).
- Презентация на 5 слайдов, тайминг защиты и видео-страховка.

## Файлы
- `stitcher.py` — Скрипт сшивки и оптимизации изображений.
- `demo_assets/` — Папка для красивых планов этажей, фотосфер и QR-кодов.
