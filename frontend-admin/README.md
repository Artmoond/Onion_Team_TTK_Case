# 🛠 Студия организатора (Участник №2)

## Зона ответственности
- Веб-конструктор для отелей и экспоцентров.
- Загрузка плана здания и расстановка точек интереса (POI).
- Разметка графа проходов (узлы, коридоры).
- Экран публикации: ссылка `/m/{slug}` и генерация печатного QR-кода.

## Запуск
Сервис автоматически поднимается в Docker Compose на порту **3001**:
http://localhost:3001

Для локального запуска без Docker:
```bash
npm install
npm run dev
```
