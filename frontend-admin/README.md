# 🛠 Студия организатора (Участник №2)

## Зона ответственности
- Веб-конструктор для отелей и экспоцентров.
- Загрузка плана здания и расстановка точек интереса (POI).
- Разметка графа проходов (узлы, коридоры).
- Экран публикации: ссылка `/m/{slug}` и генерация печатного QR-кода.

## Вход
Студия открывается только после входа с ролью **организатор**. Регистрация требует код приглашения (по умолчанию `TTK-ADMIN-2026`). Демо-аккаунт: `admin@ttk.local` / `Admin12345!`.

Переключатель «Посетитель» на экране входа ведёт в мобильный клиент. Адрес можно переопределить через `VITE_CLIENT_URL`, API — через `VITE_API_URL`.

## Запуск
Сервис автоматически поднимается в Docker Compose на порту **3001**:
http://localhost:3001

Для локального запуска без Docker:
```bash
npm install
npm run dev
```
